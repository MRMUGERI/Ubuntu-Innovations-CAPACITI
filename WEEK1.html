1. Business Requirements Analysis

Ubuntu Innovations (Pty) Ltd is relocating to a modern office in Cape Town, South Africa. This infrastructure plan provisions high-throughput wired and wireless connectivity for exactly 25 active users across five departments, eliminating redundant hot-spare hardware to optimize procurement costs while maintaining operational stability.

Corporate Structure & User Distribution (25 Endpoints Total)

  • Executive Management (3 Endpoints): 3 mobile laptops requiring confidential communication, encrypted endpoints, and boardroom Wi-Fi coverage.
  • Finance (4 Endpoints): 4 stationary desktop workstations on dedicated Cat6 drops requiring strict subnet isolation, accounting ledger integrity, and POPIA compliance.
  • Human Resources (3 Endpoints): 3 stationary desktop workstations requiring data privacy controls for employee records and onboarding portals.
  • Sales & Marketing (7 Endpoints): 7 stationary desktop workstations utilizing CRM workflows, client outreach, and shared marketing asset repositories.
  • Software Development (8 Endpoints): 6 stationary desktop PCs for intensive compiling/Docker environments, plus 2 high-performance mobile laptops for Senior Lead Developers.

5. Tier-1 Troubleshooting Standard Operating Procedures (SOPs)

Incident 1: Desktop Workstation Fails to Power On (Hardware Support)

Symptoms: User presses front power switch; zero fan spin, no chassis or motherboard LEDs, monitor displays "No Signal".

  1. Confirm the IEC C13 power cable is firmly seated into the desktop power supply and the wall/desk power rail.
  2. Verify the desk power strip switch is ON and illuminated; test socket voltage with a known-good test device.
  3. Inspect the rear PSU rocker switch and ensure it is toggled to the "I" (ON) position.
  4. Swap the IEC power cord with a verified working unit to rule out internal wire breaks.
  5. Perform a flea-power discharge: disconnect the power lead, hold the power button down for 30 seconds, reconnect power, and attempt to boot.
  6. If the unit remains unresponsive, open the side chassis to verify the 24-pin ATX power harness and test PSU output with a hardware power supply tester.

Verification: Desktop powers on, fans spin, motherboard passes POST with a single beep, and the OS boots to login prompt.

Incident 2: Endpoint Experiences Complete Internet & Network Loss (Network Support)

Symptoms: Browser reports DNS_PROBE_FINISHED_NO_INTERNET; system tray shows a globe/warning icon ("No Internet Access").

  1. Inspect the physical RJ45 wall drop and PC NIC port: verify link and activity LEDs are actively illuminated.
  2. Open Command Prompt / Terminal and run ipconfig /all (or ip a) to verify if the machine has a valid VLAN 20 IP (192.168.20.X) or an APIPA address (169.254.X.X).
  3. Test the local TCP/IP stack: ping 127.0.0.1.
  4. Test the local default gateway: ping 192.168.1.1.
  5. Test external connectivity and DNS resolution: ping 8.8.8.8 followed by nslookup google.com.
  6. Replace damaged patch cord with a certified Cat6 snagless cable or toggle the network interface card.

Verification: Machine obtains a valid DHCP lease from the router and external web pages load without latency.

Incident 3: Shared Network Laser Printer Displays "Offline" (Peripheral Support)

Symptoms: Print jobs stall in queue with status "Error - Offline"; users across HR and Finance cannot print.

  1. Inspect printer touchscreen for paper jam alerts, out-of-toner notifications, or active sleep lockup.
  2. Print a Configuration Sheet from the printer hardware menu to confirm link status and assigned IP address.
  3. Ping the printer's static IP (192.168.30.10) from an admin workstation and verify access to its Embedded Web Server (EWS).
  4. Verify on the firewall router that the printer's MAC address is assigned to its permanent static DHCP reservation.
  5. Restart the local print subsystem via administrative command line: net stop spooler && net start spooler.

Verification: Printer status updates to "Ready" across all client queues, and a printer test page prints successfully.
